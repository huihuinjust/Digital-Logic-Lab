# Digital Logic Lab

数字逻辑电路互动教学网页。第一版覆盖九章课程结构，并优先实现逻辑门、组合逻辑、时序计数器、555 脉冲和 AD/DA 的交互演示。

线上地址：https://digital-logic-lab.pages.dev

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

Cloudflare Pages 推荐设置：

- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`
